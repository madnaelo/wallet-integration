# Swap Aggregator MVP (0x + MetaMask)

Production-ready MVP using:
- Next.js (TypeScript, App Router)
- ethers.js
- MetaMask (EIP-1193)
- Backend: Next.js Route Handler `/api/quote` calling 0x Swap API
- Spring Boot backend for wallet-owned swap history

## Setup

See [docs/local-and-deployment.md](docs/local-and-deployment.md) for the local Postgres, Spring Boot, frontend, Docker Compose, and OCI deployment workflow.
